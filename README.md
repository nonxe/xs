# XS Stream 🎬

A modern, fast, pure dark-themed web application for searching, streaming, and downloading videos. Built for Vercel deployment.

## Features ⚡

- **Pure Dark / Simple Black Theme**: Custom CSS design system with subtle neon accents and glassmorphism.
- **Instant Search**: Search through thousands of videos using the search API:
  `https://apis.davidcyril.name.ng/search/xvideo?text={prompt}`
- **Inline Streaming**: Instant video stream fetching and playback using the detail API:
  `https://apis.davidcyril.name.ng/xvideo?url={url}`
- **One-Click Downloads**: Direct video file download links provided inside the video player modal.
- **Responsive Layout**: Mobile-first grid design, keyboard navigation support (ESC to close modal), loading skeletons, and toast notifications.

## Vercel Deployment 🚀

This repository is ready to deploy directly on Vercel:

1. Import your GitHub repository (`nonxe/xs`) into [Vercel](https://vercel.com).
2. Framework Preset: **Other** / **Static HTML**.
3. Click **Deploy**.
